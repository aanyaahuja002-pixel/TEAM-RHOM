Milestone 5

Your first PR, one step at a time.

Follow this illustrated flight checklist. Never automatically commit or push code — you hold the flight controls!

Git Buddy Co-Pilot

Standard Pull Request Workflow

1
Find an issue matching your skills

Look for labels like good first issue or help wanted.

2
Read guidelines & comments

Check CONTRIBUTING.md and comment politely to ensure nobody else is already working on it.

3
Fork the repository

Click the "Fork" button on the GitHub page to create your own copy under your account.

4
Clone and create a branch
git checkout -b fix/my-first-contribution
5
Make a small, focused change

Edit only what is necessary to solve the issue. Keep diffs clean and easy for maintainers to review.

6
Test your changes
npm test
7
Commit and push your branch
git commit -m "fix: resolve typo in docs"
8
Open a Pull Request

Go to the original repo on GitHub, click "Compare & pull request", fill out the template, and submit!
